2. Description of Game Services

BrainBox is an all-in-one casual gaming application offering offline gameplay across ten classic titles:

  • Queen: Logic crown placement puzzle across colored regions, rows, and columns.
  • ZIP: Sequential number pathfinding puzzle filling every grid cell.
  • Sudoku Master: Classic 9×9 logic grid puzzle with notes, hints, and 3 difficulty levels.
  • 2048 Neon: Slide-and-merge number strategy puzzle with undo support.
  • Block Puzzle: 10x10 geometric grid puzzle with multi-line clear combos.
  • Tic Tac Toe: 3x3 strategy grid with 3 bot AI difficulty levels and 2-Player Pass & Play mode.
  • Snakes & Ladders: Authentic 100-tile board game with 3D animated dice, interactive obstacles, customizable avatars, and 2-Player Pass & Play mode.
  • Memory Match: Card-flip memory trainer with fruit icons and score tracking.
  • Retro Snake: Arcade handheld game with responsive touchscreen controls.
  • Fruit Slicer: Swipe-action arcade game with slicing combos and hazards.

All core gameplay features function completely offline on your device.
